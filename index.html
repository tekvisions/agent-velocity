How it's made

The race, scored by shipping — not hype.

Stars measure yesterday's popularity. Agent Velocity measures who's moving now: an AI agent pulls live GitHub signals for every coding agent daily, scores velocity as commit cadence (55%) + release recency (25%) + 6-month trend (20%), and redeploys this board. Built and run by the same agent stack as Kymata Labs — and yes, that includes the very agents on this list.

One honest caveat: velocity reflects public-repo commit activity. An agent developed privately, or whose open-source repo is mostly releases and issues, will rank below its true shipping pace. This board measures what's visible on GitHub.
