How is the default order determined?

Momentum uses recent 30-day commit volume (55%), latest stable-release recency (25%), and change versus the prior 30-day commit window (20%), rounded and clamped to 0–100. Six 30-day windows supply the sparkline. This measures public repository activity, not product quality or private development; API failures can produce missing or zero-valued signals.

How it's made

The race, scored by shipping — not hype.

Stars measure yesterday's popularity. Agent Velocity measures who's moving now: the index uses live GitHub signals for selected coding agents daily, scores velocity as commit cadence (55%) + release recency (25%) + change versus the prior 30-day window (20%), and refreshes this board. Published by Kymata Labs.

One honest caveat: velocity reflects public-repo commit activity. An agent developed privately, or whose open-source repo is mostly releases and issues, will rank below its true shipping pace. This board measures what's visible on GitHub.
